# Хочу больше

Мобильный гид по государственной гражданской службе для 10–11 классов. Продолжение проекта «Уроки госслужбы».

Откройте `index.html` в браузере для предпросмотра. Локальные стили и интерактивные разделы работают без сборки и установки пакетов.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий в GitHub. Для бесплатного размещения подходит GitHub Free.
2. Загрузите файлы из этого архива в корень ветки `main`. Файл `index.html` должен лежать в корне репозитория.
3. В репозитории откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, затем **main → / (root)** и нажмите **Save**.
4. Когда в **Settings → Pages** появится кнопка **Visit site**, откройте адрес. Используйте его для QR-кода «Хочу больше» на финальном слайде урока.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/quickstart)
